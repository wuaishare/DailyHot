# 主指标弱化设计

## 目标

保留阅读、点赞、收藏和热度的榜单语义，但让主指标回到辅助信息层级，不再呈现为醒目的徽章。

## 设计决定

- 当前榜单的主指标继续排在第一位，并保留 `is-primary` 语义类。
- 主指标与普通指标使用相同的间距、边框、背景、圆角和字重。
- 主指标唯一的视觉差异是文字采用当前主题的主色。
- 指标标签和值同时着色，避免只给数值着色造成语义割裂。
- `CategoryStream`、`CategorySourceRail` 和旧版 `List` 的主指标只使用主题文字色。
- `HotList` 的鼠标悬浮预览保持原有中性 Meta 层级：作者/发布时间 + 阅读/点赞/评论/收藏，不参与主指标强调，也不把“热度”注入 metrics。
- 阅读、点赞、评论、收藏、作者和发布时间的内容、排序与缺失值处理不变。

## 可访问性

颜色不是主指标语义的唯一载体：主指标仍排在第一位，并由现有文字标签明确写出“阅读”“点赞”“收藏”或“热度”。亮色与深色主题继续使用既有主色 token。

## 验收

1. 自动审计确认正文消费入口保留 `is-primary` 文字色语义，同时 `HotList` 悬浮预览明确使用 `promotePrimary: false` 且不存在 `.preview-metric.is-primary`。
2. `npm run build` 完整通过。
3. 生产 `read-30d`、`like-14d`、`collect-30d` 和 `hot` 页面只以文字颜色区分主指标。
4. 亮色、深色和 390px 移动端无回归，控制台无错误或警告。
